The owner authorized a separate Pro Cloud per-book flow on 21/10/2026: Lite Vietnamese + Kitten English are free; Existing Pro orders keep the authenticated Modal pipeline; new catalog snapshots use the explicitly versioned HeyGen contract, with private owner-device trial gateway/dispatcher authorized and deployed on 23/10/2026; paid/public deployment remains deferred. Do not offer new annual subscriptions. Preserve old licenses and payments. Network is allowed for explicit setup, explicit Pro sample/book/receive actions and bounded checks while its popup is open, plus explicit legacy-license checks. Do not add analytics or LLM rewriting. Keep originalText separate from any synthesis normalization; Qwen may direct prosody, not rewrite the stored book. Do not enable paid cloud service, deploy or ship private F5 assets until commercial rights and deployment scope are explicitly confirmed; never include the training dataset. Bind orders to the hashed Mac code plus a separate random Keychain credential; no customer account/email is required. Optional online listening has separate pricing deferred; exported web packages are authorized, while actual publication/upload needs the user's selected destination/action. See docs/BOOK-COMMERCE.md for the current price table, queue and activation status.

- Preserve source text and Vietnamese diacritics. Segment boundaries must partition text verbatim. Retain originalText separately from corrections.
- Persist atomically after each page and completed audio segment. Cancellation must retain completed work; interrupted output must never count as usable audio.
- Cache audio by text + voice + engine/model revision. Playback speed is a player setting; it must not invalidate audio. Changing text or voice must never play stale audio.
- Keep stdout JSON-lines only in worker/engine/extractor. Diagnostics go to stderr or project-local logs. Native bridge actions must be explicitly whitelisted.
- Use local assets/system fonts; no remote UI assets. Respect dark mode, reduced motion, reduced transparency, increased contrast, keyboard focus and accessibility labels.
- Glass is for navigation and controls. Keep the document surface readable. Do not rerun entrance animation on progress or playback ticks.
- Build with ./scripts/build.sh. Run core tests for processing/state changes. Run real integration when extraction/inference contracts change. Verify native UI after visual changes. Do not add implementation-mirroring tests for a cosmetic edit.
- Use isolated .qa libraries for fixtures. Do not present fixture tests as proof of arbitrary books, all voices, older macOS versions or public distribution.
- No publishing, paid services, installer release or modifications outside this project without explicit scope. Local development app is not a portable/notarized release.

- Generation and export must honor the same page/range/chapter selection. Chapter boundaries come from EPUB navigation/headings, PDF outlines, source PDF typography with a verified numbered heading sequence (owner authorized 22/10/2026), or explicit manual markers; do not invent semantic chapters from prose. A chapter can begin midway through a page or have its number/title on consecutive pages: use segment membership, never just page ranges.
- The owner authorized an optional selected-PDF cloud processing pipeline on 22/10/2026 alongside a fully local default. Do not auto-upload when Wi-Fi appears. Keep raw source and review proposals separately; Qwen corrections require review rather than silently rewriting names/numbers/content. Cloud processing service code and owner upload CLI may be prepared locally, but deployment, quota-spending inference and the customer upload gateway remain separate activation work; no merchant/proxy key may enter the customer app. The 30-second import target is measured on the selected 203-page test book, not a guarantee for arbitrary scans or TTS.
- Music selection and gain must survive reopening and be included in WAV/M4A/web exports without invalidating narration cache. Preserve user-provided originals. User demo recordings are local-only assets unless explicitly authorized for publication.

- Launch offer authorized 22/10/2026: one 50,000 VND / 5-book combo per Mac; both purchase and all redemptions close at 2026-11-02T00:00:00+07:00. No unlimited 15k sale or 5k short-book sale; individual books keep book-v1. Snapshot-bound retries never consume another combo slot. Preserve existing orders/payments; deployment and paid activation are still separate scope. See docs/LAUNCH-COMBO.md.

- On 23/10/2026 the owner revised the platform decision: Mac, PC and Android remain independent, with local profiles and per-device trials/purchases; no Soundbooki account, Google/Gmail login, OAuth or cross-device book/audio synchronization. Users may export generated audio and manually play it on other devices. Preserve used trials, old orders and Mac combo terms. Automatic store/bank verification and a fair, account-wide provider rate limiter remain required before paid activation; provider account-wide limits do not imply shared customer accounts. Do not add permanent cloud libraries or silently delete existing data. StoreKit/Play Billing and paid/public dispatcher activation remain separate work; owner-device HeyGen trial gateway/dispatcher was explicitly authorized and deployed on 23/10/2026 (see docs/CLOUD-TRIAL-DEPLOYMENT.md); see docs/DEVICE-PAYMENTS-AND-QUEUE.md.
